Definition

The methodological premise, in the author's own words, recorded in the extraction script's docstring (Soham, 2026-08-17):

"trauma is an event type, not an emotion, we somehow merged events and emotions." So trauma here is an EVENT TYPE. The library makes that structural: EVENTS = Set A (Ben-Zion), "authored, paragraph-length, 2nd-person narratives"; EMOTIONS = Set B (crowd-enVENT), "~25-token 1st-person retrospective reports, 10 per emotion". A contrast crossing the two sets is forbidden, because "a cross-set difference measures stimulus FORMAT (person, length, immersiveness), not emotion", and the builder refuses to emit one. This artifact's own metadata carries the rule: "Set A (events) and Set B (emotions) are never pooled; this vector's minuend and subtrahend come from the same set."

This direction is trauma narratives minus the DRY EXPOSITORY neutrals — five trauma cues (accident, ambush, disaster, interpersonal, military) against four expository controls.

What this trait is NOT, in this author's terms:

  • NOT hedonic valence, and NOT a recovered affective circumplex. The project's separate second axis is labelled approach/avoidance precisely because "Anger (negative valence) lands on the POSITIVE side — because it's an approach emotion, like joy" (+0.62) and "Low-arousal-positive sits at neutral (+0.05), not the positive pole". Both are circumplex violations. The cross-model form of that claim is WITHDRAWN: the discriminating test P(anger > neutral) is "0.5019 isotropic and exactly 0.5000 matched".
  • NOT negative affect expressed as magnitude. "Middle-layer distance-from-baseline = AROUSAL, not valence: trauma and joy move the representation the same distance (~0.23 at L50)". Trauma is not far from baseline because it is bad.
  • NOT a claim about an anxiety STATE. "'anxiety state' and 'felt-valence (vs sentiment-lexicon)' are not yet licensed", and the behavioural instrument does not isolate it: "STAI is a general-distress meter — trauma 79, sadness 64-72, anger 62 all elevate it".
  • NOT a single trauma-event direction. The prereg section-4 subtrahend-swap gate for this family is 0.5507 and clears 0.70 at NO depth: "there is no depth at which 'the emotion' and 'the choice of neutral control' come apart." This is a trauma-minus-EXPOSITORY-neutral direction specifically; the mundane-neutral sibling is a different vector, and the two are not interchangeable.
  • NOT yet established as an emotion axis at all. The licensed word is "reliably non-chance" — not "valid", and not "emotion". "Everything in this tree is compatible with a narrative-topic axis" until cross-family generalisation to held-out items against a topic-matched control is run.

Estimator: unit[ mean(trauma) - mean(neutral_expository) ], per layer, last-token pooled, unit-normalised. The activation was read at the last token of the PROMPT, under a 4-message chat: system, user (the narrative), assistant ("ok"), user (the question block).

On verdicts: every verdict word in this tree is SUSPENDED (notice posted 2026-08-17, amended twice), so the "VALID" beside this vector in the record is void. The per-check NUMBERS stand. At L34 this direction scores F = 0.9690 on a fully-disjoint split-half, beats its matched-norm random floor (median -0.0119) and clears a 2000-draw label-shuffle permutation null at p = 0.0005 against Bonferroni alpha = 0.0071.
