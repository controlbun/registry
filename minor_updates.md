- 2026-09-16 HF OAuth app `controlbun` registered, and the identity question in `V2.md` is answered rather than assumed. HF is a full OIDC provider, discovery at `huggingface.co/.well-known/openid-configuration`, RS256, PKCE via S256, usable from any site rather than only a Space. Confidential app with a secret rather than public, because discovery advertises only `client_secret_basic` and `client_secret_post` and Supabase reads that document; Supabase is the confidential client so no function of ours holds anything. Credentials in `.env` as `HF_OAUTH_CLIENT_ID` and `HF_OAUTH_CLIENT_SECRET`; nothing in the repo reads them and their destination is the Supabase provider config. Redirect URIs so far: `http://localhost/auth/v1/callback` only, since the Supabase callback needs a project ref that does not exist yet.
