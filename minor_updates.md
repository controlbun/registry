- 2026-09-13 Trademark filing deliberately deferred, not skipped. `controlbun` returns zero on a USPTO wordmark search; the general search's 2,567 hits are fuzzy matches on `control`, which is crowded in the software classes, and a crowded term is mildly in our favor since nobody owns it. The filing basis will be intent-to-use, Section 1(b): it can be filed before any use in commerce and its filing date becomes a constructive date of first use, which is what closes the gap left by having no use yet. Classes 009 and 042 only, because an ITU requires bona fide intent for everything listed and padding classes is a vulnerability rather than free optionality. Cost is $350 per class at filing and $150 per class later for the Statement of Use, so $700 now and $300 later; pick goods descriptions through the ID Manual selector rather than typing or pasting into the free-form box, which adds $200 per class. Fees are non-refundable, so the wait buys certainty about the name for the price of a month of priority. **Trigger, not a date: file before `controlbun` appears anywhere public with real traffic**, and do npm and PyPI package names in the same sitting since all three are gated on the same event.
